# The Astral Sea — Releases

Downloads for **The Astral Sea**, a dimension mod for Minecraft 1.21.1 (Fabric).
This repository only holds release files; there is no source code here.

## Pre-alpha 0.1.0

- Minecraft 1.21.1, Fabric Loader 0.19.5 or newer, Fabric API (0.116.17+1.21.1)
- Optional: Sodium and Iris. Complementary Reimagined and Rethinking Voxels are supported.
- There is no portal yet: in a world with cheats enabled, use `/astralsea tp` to enter the dimension.
- This is a pre-alpha. Expect bugs and missing content, and back up your worlds.

Download the `.jar` from the [Releases](../../releases) page and put it into your `mods` folder.
